Data Flow

User interacts with a filter
FilterBar updates shared refs in the useFilters composable — warehouse, category, status, month.
View calls the API client
Views like Dashboard.vue invoke methods on src/api.js, passing the active filters.
axios sends HTTP GET with query params
Filters become URL query parameters — ?warehouse=A&category=sensors&month=Q1-2025.
FastAPI route applies filters in memory
Shared helpers apply_filters() and filter_by_month() narrow the dataset. Quarters like Q1-2025 expand to month lists.
Pydantic validates the response
Models (InventoryItem, Order, ...) enforce structure and types before serialization to JSON.
Vue refs update; computed properties recalc
Raw data lives in refs (allOrders, inventoryItems). Derived values — totals, charts, status counts — flow from computed properties.
Template re-renders
Reactivity pushes fresh numbers into cards, tables, and SVG charts without manual DOM work.

Key Design Decisions

Filters as shared state
Four global filters (time period, warehouse, category, status) live in a composable and are threaded through every API call as query params — one source of truth across views.
In-memory, no database
JSON files loaded once at startup. Fast to iterate, zero infrastructure, but mutations are ephemeral — a restart resets state.
Refs raw, computed derived
Raw data stays in refs; all totals, groupings, and chart inputs are computed properties. Cached, predictable, no manual invalidation.
Pydantic at the seam
Response models validate every payload before it leaves the server, catching JSON/schema drift at the boundary instead of in the UI.
Demo application · Vue 3 + FastAPI · In-memory data · Not production-hardened.
